## Mortgage-Calculator
# Overview
This project is a simple Python-based mortgage calculator that allows users to estimate their monthly mortgage payments based on three key inputs:
- Loan principal
- Annual interest rate
- Loan term in years

The calculator uses the standard mortgage payment formula to compute the monthly payment and formats the result as U.S. currency for easy readability.

# Why I created this project
I created this project to practice working with user input validation, loops, and financial calculations in Python. Mortgage calculations are a common real-world application of compound interest, so building this calculator helped reinforce how mathematical formulas can be translated into code.

This project was also a good way to practice writing cleaner code using constants, loops, and conditional logic to ensure that user inputs fall within reasonable ranges.

# How it works
The calculator asks the user to input:
- Principal amount (between $1,000 and $1,000,000)
- Annual interest rate (between 1% and 30%)
- Loan term in years

The program then converts:
- The annual interest rate into a monthly interest rate
- The loan term into the total number of monthly payments

Technologies Used
- Python
- Basic mathematical finance formulas
- User input validation with loops and conditionals
